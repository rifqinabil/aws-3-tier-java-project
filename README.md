
# AWS 3-Tier Java Application

## Project Overview
This project demonstrates the deployment of a Java web application using AWS 3-Tier Architecture.

## Architecture

1. Presentation Tier: Nginx
2. Application Tier: Java Application with Apache Tomcat
3. Database Tier: MySQL

## AWS Services
- Amazon VPC
- Amazon EC2
- Amazon RDS
- Elastic Load Balancing
- Auto Scaling
- Amazon CloudWatch
- AWS Security Groups
- AWS IAM

## Project Objectives
- Understand AWS networking and infrastructure.
- Deploy a Java web application.
- Implement a 3-Tier architecture.
- Configure security and monitoring.
- Document deployment procedures.
